JavaScript Trivia Quiz CLI

Description

This project is a command-line trivia game built using JavaScript and Node.js. It allows users to answer multiple-choice questions, receive feedback, and view their final scores.

Features

Interactive command-line interface

Multiple-choice questions

15-second timer for each question

Instant feedback on answers

Score and percentage calculation

Option to replay the quiz

Technologies Used

JavaScript

Node.js

Readline module

How to Run

Clone this repository.

Open the project folder in your terminal.

Run the following command:

node quiz.js

Type START to begin the game.

Testing

The application was tested using Node.js to check syntax, user input, answer accuracy, timer functionality, and final results.
